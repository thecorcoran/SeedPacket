# Seed Envelope Fonts

This directory contains locally bundled `.woff2` web font files to allow the Seed Envelope Maker to run completely offline with no network dependencies.

## Included Fonts

1. **Rye**
   - **Designer**: Nicole Fally
   - **License**: SIL Open Font License (OFL), Version 1.1
   - **Origin**: Google Fonts (`https://fonts.google.com/specimen/Rye`)
   - **Style**: Victorian wood type, Western display serif, ideal for vintage seed packet headers.

2. **Abril Fatface**
   - **Designers**: TypeTogether (Veronika Burian, José Scaglione)
   - **License**: SIL Open Font License (OFL), Version 1.1
   - **Origin**: Google Fonts (`https://fonts.google.com/specimen/Abril+Fatface`)
   - **Style**: Dramatic 19th-century Didone display face with high contrast and classic poster presence.

3. **IM Fell English (Regular & Italic)**
   - **Designer**: Igino Marini (digitization of the historic 17th-century types of Bishop John Fell at Oxford University Press)
   - **License**: SIL Open Font License (OFL), Version 1.1
   - **Origin**: Google Fonts (`https://fonts.google.com/specimen/IM+Fell+English`)
   - **Style**: Authentic antique letterpress texture, used for Latin binomial names, variety titles, and harvest notes.

4. **Libre Caslon Text (Regular & Italic)**
   - **Designers**: Impallari Type, Rodrigo Fuenzalida
   - **License**: SIL Open Font License (OFL), Version 1.1
   - **Origin**: Google Fonts (`https://fonts.google.com/specimen/Libre+Caslon+Text`)
   - **Style**: Classic William Caslon revival with clear readability for smaller catalog print.

## System Fallbacks

If web fonts are disabled or unavailable in the environment, the CSS font stack cascades to high-quality system serifs:
`'Playfair Display', 'Baskerville', 'Georgia', 'Garamond', 'Times New Roman', serif`.
